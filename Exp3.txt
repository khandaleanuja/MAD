2. <Text> component is used for display text.


<StyleSheet>  : 
React native doesn't use css file instead it uses <StyleSheet> component. It stores all styles in one place.
Advantages :
1. Reusable
2. Clean code
3. Easy to maintain


<ScrollView> :
It renders everything at once, suitable for small amount of data 
Example : about page, profile page, setting page, terms and conditions page

<FlatList> : 
It loads only visible items, best for large data
Example : WhatsApp chat, instagram feed, amazon product
